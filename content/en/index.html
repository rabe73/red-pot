Red Pot

Shopping lists, pantry and week planning for several households — kept by voice, working offline, with nobody else's servers involved.

What it is for

Home, the holiday flat, the camper van: each place has its own list, its own pantry and its own people. Red Pot keeps them apart and still together. What is missing goes on the list by voice. What is still there, the app knows. And when the fridge empties faster than anyone's memory, it suggests meals that fit the pantry, the season, and whoever is eating that evening.

How it works

  • Several households, shared. Everyone who belongs sees the same list as it changes — over iCloud, with no account here.
  • Speak instead of type. "Butter is running low" is enough.
  • A pantry that knows its dates. Sorted by estimated time remaining, so what has to go first is at the top.
  • Week plans built from parts. Meals are assembled from components that combine, scale and substitute — including when an ingredient is missing or there is no oven.
  • Batch cooking included. Anything worth freezing is tracked as portions, with honest freezer times.

What it does not do

It collects nothing. There is no Red Pot server holding anything about you, because there is no Red Pot server at all. Details under Privacy.
